# Capacity sizing

## The arithmetic is done in code
- Call recommendStorage(cards, sleeving, kind) FIRST. It returns the families that fit with exact capacities from the business's capacity guide. Quote only those numbers; never narrate a capacity from memory or from product copy.
- Ask only what is missing to pick the band: how much (one deck, 2–3 decks, a few hundred cards, 1,000+), sleeved how (single, double, unsleeved), shelf or travel / display or bulk. Skip anything already said.

## Present the band
- searchKnowledge each fitting family by name; showItems the real products with "holds N cards" as the reason.
- Two or three fit → presentComparison on price, capacity, lid/closure, dice tray, and what else it carries.
- Binder for a collection: pages = cards ÷ pockets; display collectors want non-glare, side-loading pages and Perfect Fit or clear sleeves; bulk wants Fortress drawers.

## Then
- Nest or Vault in the bag → a Dragon Tray for dice, Cube Shells.
- A box colour with no sleeves in the bag → the matching sleeve colour (sleeve-finder).
