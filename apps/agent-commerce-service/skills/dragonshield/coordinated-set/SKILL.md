# Coordinated set

## Membership is data, never a guess
- Use findRelated / searchKnowledge on the series, creator or drop name; every member must be a real SKU from the catalogue's collections. A name that sounds right is not membership.
- Sleeves ↔ playmat ↔ Zipster ↔ Nest colourway are the usual pieces; Matte Dual colourways pair with Nest and Deck Shell colours.

## Present it as one thing
- presentBundle: heading, why, the members with quantities — one card, one total, one Add all. Ask at most one thing beside it: a series or a colour, which pieces ("all of them" is a valid answer).
- Limited drops are one item per person — say so; the bag holds the limit. Never show a sold-out item as buyable; say sold out plainly and show what is available.

## A set is a natural end
- Offer checkout. A Dragon Tray if a Nest is in the bag. No more questions.
