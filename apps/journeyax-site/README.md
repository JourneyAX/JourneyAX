# JourneyAX Marketing Site Prototype

High-fidelity, multi-page static prototype based on the JourneyAX website blueprint.

## Pages

- `index.html` — business-led homepage
- `platform.html` — platform layers and Journey Studio
- `experience.html` — 40/60 Experience Canvas
- `solutions.html` — outcome-led solutions and industries
- `customers.html` — experience gallery and proof standard
- `architecture.html` — enterprise and runtime architecture
- `security.html` — security, AI governance and trust
- `pricing.html` — recommended commercial packaging
- `docs.html` — role-based documentation portal concept
- `contact.html` — journey workshop conversion flow

## Shared assets

- `styles.css` — responsive JourneyAX black/yellow design system
- `site.js` — navigation, tabs, demo, accordions and reveal behavior
- `assets/og-journeyax.png` — generated social-preview card

The prototype is intentionally framework-free and can be served from any static web server. Production implementation should connect forms, analytics, consent, CRM, documentation search and the safe JourneyAX demo tenant.
