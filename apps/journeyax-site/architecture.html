Context architecture

Keep the minimum useful context—not the maximum possible transcript.

JourneyAX combines recent turns with a structured journey state and compact summary, then retrieves long-term facts only when relevant.

A

Working context

Recent messages, current intent, active products and tool results needed for this turn.

B

Journey memory

Structured slots, decisions, items shown, rejected options, phase and outcome state.

C

Retrievable memory

Conversation summary, customer preferences, prior journeys and relevant knowledge.

AvoidContext overload
  • 01Sending the entire transcript every turn
  • 02Repeating every retrieved document
  • 03Using text history as the only journey state
  • 04Allowing tool output to grow without projection
JourneyAX approachPurposeful context
  • 01Rolling summary plus recent conversational turns
  • 02Structured state for business decisions and progress
  • 03Intent-routed retrieval with source and scope filters
  • 04Capability results narrowed to fields needed to decide
