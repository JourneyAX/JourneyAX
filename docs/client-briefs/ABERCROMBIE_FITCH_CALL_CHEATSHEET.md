# A&F Call Cheatsheet (keep this open)

## Open (30s)
"JourneyAX is an AI sales consultant on your site — not a FAQ bot. Customer states a goal, we clarify, pull real catalog products, and convert in one conversation. Same pattern we ran for Caroma bathrooms and Augusta team kits."

## Lead 3 use cases
1. **Personal Stylist** — "Style me for a rooftop party" → quiz → edit → bag · **Conversion + AOV** · *Already prototyped*
2. **Denim Fit Finder** — fit / rise / wash / length · **Denim conversion** · Signature category
3. **Fit & Size Advisor** — usual size → recommended size from charts · **Returns ↓** · Best ROI story

## Backup if they lean in
- Complete-the-Look (UPT)
- Trip packing / gift concierge (AOV / seasonal)
- NFL / game-day vibe (Augusta sportswear pattern)
- myAbercrombie concierge (retention)
- Care / returns / policy RAG (ticket deflection)

## Demo lines
- "Style me for a rooftop party."
- "Baggy 90s jeans, mid rise, dark wash."
- "I usually wear a 28 — what size here?"

## Proof points
- Grounded in real catalog (no invented SKUs)
- Server-authoritative price / promo
- Config persona — not custom code per brand
- Multi-tenant: A&F today, Hollister later

## Ask to close
"6–8 week pilot: Stylist + Denim Finder + Size Advisor on a catalog slice. Success = agent session conversion/AOV vs baseline, plus denim return hypothesis."

## Questions to ask them
1. Biggest discovery pain: denim / occasion / gift / mobile?
2. Denim return rate today?
3. Catalog + size-chart systems?
4. myAbercrombie API access?
5. Pilot success metric?
