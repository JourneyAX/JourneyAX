# Location services (sample)

Stands in for: **Cotality location APIs: address checks, maps and distances**.

Check an address, find the nearest branch and estimate the drive. This is **sample data**: a stand-in that speaks MCP at `POST /mcp/location`. Generated by `scripts/build-seeds.ts`; do not edit by hand.

## Records

| Collection | Records | Origin | Marked `sample: true` | Real fields (copied from the PlaceMakers data) | Made-up fields |
|---|---|---|---|---|---|
| `addresses` | 32 | made up | 32/32 | town (a real branch town) | every other field |
| `branches` | 65 | real and made up | 65/65 | code, name, phone (street addresses are left out: the website text in the data folder has lost characters from them) | lat, lng (approximate town centre, entered by hand) |

Smallest allowed per collection (a test checks it): addresses 25, branches 25.

## Tools

- `find_address`: Find addresses by words.
- `validate_address`: Check an address typed by a person: is it a real address, and if not, what is close.
- `nearest_branch`: The branches nearest to an address (by its id) or to a point (latitude and longitude), nearest first.
- `drive_time`: An estimate of the drive from an address or point to a branch: distance and minutes.

Records that are invented, or that mix real and invented values, carry `sample: true`. The people, trade businesses, customer phone numbers and email addresses are made up (emails end in `.test`); any resemblance to a real person or business is chance. Branch names, codes and phone numbers are the ones the PlaceMakers store locator page lists. No customer data was read.
